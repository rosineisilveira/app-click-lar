# ClickLar App - Aplicativo Mobile

Aplicativo mobile desenvolvido em **React Native** para conectar clientes a prestadores de serviços, permitindo o cadastro, busca e gerenciamento de anúncios diretamente pelo smartphone.

## 🚀 Tecnologias Utilizadas

* **Framework:** React Native (Expo / CLI)
* **Linguagem:** JavaScript / TypeScript
* **Navegação:** React Navigation
* **Cliente HTTP:** Axios
* **Armazenamento Local:** AsyncStorage (gerenciamento de sessão e tokens)
